# Resume Generator Prompt

Create a professional ATS-friendly resume using the following user details.

## Input Fields

- Name: XXXXX
- Email: XXXXXXX
- Phone: XXXXXXX
- Education: XXXXX
- Projects: XXXXX
- Skills: XXXXX
- Experience: XXXXX
- Certifications: XXXXX
- Achievements: XXXXX

## Requirements

1. Generate a modern professional resume.
2. Keep the format ATS-compatible.
3. Use proper section headings:
   - Profile Summary
   - Education
   - Skills
   - Projects
   - Experience
   - Certifications
   - Achievements
4. Use bullet points where necessary.
5. Keep the resume within 1–2 pages.
6. Use clean formatting with readable fonts.
7. Highlight technical skills and project impact.
8. Create concise and professional content.

## Project Section Format

For each project include:
- Project Name
- Description
- Technologies Used
- Key Features
- Outcome/Impact

Example:

### Project
**AI Resume Generator**
- Built an ATS-friendly resume generation system.
- Technologies: React, Node.js, MongoDB
- Features:
  - Dynamic templates
  - PDF export
  - AI content suggestions

## Output Format

Generate the final resume in:
- Markdown format
- PDF-ready structure
- Clean and professional layout
